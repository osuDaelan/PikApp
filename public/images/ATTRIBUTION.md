## Individual card designs — October 27, 2026

The [Chess Piece gallery](https://www.pikminwiki.com/Special_Decor_Pikmin#Chess_Piece) supplies seven white pieces (`_1.png`, reused) and seven black pieces (`_2.png`, retrieved October 27). Each now maps to its own side/species checkbox. Original file URLs, dimensions and checksums are recorded in the inventory; former grouped mappings remain under `legacyGroupedImages`.

Hanafuda (24 Volume 1 and 16 Volume 2), Playing Card (27) and Mahjong Tile (27) now use separate local transparent PNGs for all 94 designs referenced in [Pikipedia's actual special-decor image tables](https://www.pikminwiki.com/Special_Decor_Pikmin). Twenty-five previously used representative files were reused for their matching exact designs and 69 missing PNGs were downloaded. The [inventory](../../docs/decor-image-sources.json) records per-design file pages, original URLs, dimensions, byte sizes and SHA-256 checksums, with the former grouped records archived under `legacyCardImages`. Artwork belongs to Nintendo; these are existing game images, not AI-generated images. Attribution does not grant redistribution permission.

## Map decor-category icons

Retrieved October 24, 2026 from the actual category symbols in [Pikipedia's Decor Pikmin table](https://www.pikminwiki.com/Decor_Pikmin#Decor_types). All 39 map categories have a local transparent PNG in `decor-categories/`, at most 64px on the longest edge. Together they total 43,247 bytes (about 42 KiB). These are existing Pikmin Bloom game symbols, not AI-generated artwork. The map and sidebar use these original symbols; the temporary emoji comparison was removed after the user chose this style.

The [category icon inventory](../../docs/map-category-icon-sources.json) records source file pages, original/download URLs, actual dimensions, byte counts and SHA-256 checksums. Nintendo retains artwork rights; attribution does not grant a redistribution license.

## Mushroom type artwork

Retrieved October 24, 2026 from the 13 type icons used in [Pikipedia's Mushroom battle tables](https://www.pikminwiki.com/Mushroom_battle). The local PNGs in `mushrooms/` use Pikipedia's thumbnails, up to 96 pixels on the longest edge, with original transparency. These are existing Pikmin Bloom game images, not AI-generated images. Each type icon is shared by its Small/Normal/Large entries; these are not size-specific illustrations.

The [mushroom image inventory](../../docs/mushroom-image-sources.json) records every file page, original URL, downloaded thumbnail URL, actual dimensions, byte count and SHA-256 checksum. All 13 icons together are 197,315 bytes. Nintendo retains artwork rights; attribution does not grant a redistribution license.

## Complete existing decor catalog

All 896 current checklist entries now have local PNG artwork, retrieved October 18, 2026 from the actual file references in [Pikipedia's regular gallery](https://www.pikminwiki.com/Decor_Pikmin#Gallery) and [special decor sections](https://www.pikminwiki.com/Special_Decor_Pikmin). Rare entries are included in this full rollout. The following pilot sections preserve the original rollout history.

The complete per-image inventory is [docs/decor-image-sources.json](../../docs/decor-image-sources.json): collection ID, local filename, original file URL, source page/gallery, dimensions, byte size, checksum, and representative-design flag. Some existing checklist entries group multiple designs; their images are explicitly marked as representatives. All assets preserve the original PNG transparency. These are existing game images, not AI-generated. Pikmin artwork belongs to Nintendo; attribution does not grant a redistribution license.
